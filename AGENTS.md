# AGENTS.md

## Project

Link manager REST API built with FastAPI, SQLAlchemy (async, PostgreSQL), Redis for caching, and Alembic for migrations.
Code lives in `src/lnkr` (`api`, `services`, `database`, `cache`, `config`, `models`); tests mirror that layout under `tests/`.

## Commands

- Setup: `just install`
- Test: `just test` - requires running Docker (testcontainers); the recipe sources `deployment/.env.common` and `.env.development`, so do not run bare `uv run pytest`.
- Lint: `just lint` (diff-only; fix with `uv run ruff check --fix` and `uv run ruff format`) / Type check: `just type`
- Full gate: `just check-all` (lint, type check, and 100% test coverage) — must pass before finishing any change.

## Policies

- Requires Python 3.14.
- PEP 758's `except A, B:` syntax is intentional; do not flag or rewrite it.
- When implementing new features, do not add tests until explicitly asked.
- Dependencies are managed with uv with exact `==` pins; `exclude-newer` in pyproject.toml is intentional. Add with `uv add 'pkg==x.y.z'`; do not upgrade unless asked.
- Schema changes: `just database-migration "message"` (autogenerated); do not hand-write Alembic revisions.
